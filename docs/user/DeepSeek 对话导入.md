# 从 DeepSeek 对话创建角色

在「模型连接」验证官方 DeepSeek API Key。网页账号用于导出历史，API Key 用于你确认后的角色分析。

1. 在「新建角色 → 从 DeepSeek 创建」展开「DeepSeek 导出图文教程」，然后点「打开 DeepSeek 并等待下载」。
2. 在浏览器登录，点账号头像，进入「设置 → 数据管理」。生成下载链接，链接就绪后点击下载。用非默认下载目录时，可在 PCAR 选择下载文件夹后再打开官网。
3. PCAR 收到 ZIP 后提示你选择一段对话。也可以点「选择已下载的 ZIP」，选中下载所得的官方压缩包。
4. 选择聊天模式和导入数量。私人聊天模式用于即时通讯。角色扮演模式用于 AI 文游，保留动作、旁白和角色心理，剧情归入这个人格的故事记忆。模式随创建的人格保存。
5. 数量可选最近 50、100、200、500、1000 条，也可选全部或填自定义数量。消息按原顺序保留，用户和助手发言都计入条数。导入超过 5000 条时，确认用时和费用后方可继续。
6. 审阅、修改或另存 Markdown，核对待分析范围，然后确认分析。检查生成的角色卡并保存，可选择带所选历史开始聊天。

从 Markdown 导入时同样可以选择模式和数量。在此候选中，角色扮演模式的模型分析、正文和记忆整理需要该模式的提示词审定后启用。
