# 导入私聊历史并接着聊

打开 v0.5 Windows 工作台或社区版 1.1.1。准备一份微信 Moect v1.3.0 私聊 Markdown，或使用二至四级标题逐条标明说话人的通用 Markdown。QQ、DeepSeek App 的双人记录经本地转换为这个格式后也可以选择。文件中明确标记用户与助手时，选择用户一侧作为本人。

1. **选择接续对象。** 在角色卡上选中要聊天的人物，将「开聊方式」设为「带历史开始」，再确认提示词预览。工作台会把另一侧标为本人，供你核对。已有角色也可在人物菜单选择「导入历史并接着聊」。
2. **核对原件。** 选文件，指定哪一方是自己、谁对应目标人物，核对逐条修订、开始与结束的消息号、排除项和原文件时区。有可靠原时间的气泡会把当时的时间提供给接话模型，正文仍按原话读取。缺少时间的气泡按文件顺序保留。工作台显示接收本次原话的模型，确认后使用所选正文。整理长期记忆是单独的选项，默认关闭。
3. **打开会话。** 保存完成后可直接从末尾发言。已有活动会话会按原生规则封存。有未完成的输入或发言时，先按窗口提示处理，再重新预览。再次导入同一范围可找回先前的会话。
4. **查找、引用和分支。** 向上翻看或用「查找历史消息」定位旧消息。打开该消息旁的「⋯」，也可在触屏上长按，选择「引用这条消息」或「从这里开启分支」。引用时，工作台读取原消息前后各最多 20 条可读消息，再带入当前输入前最多 10 条。分支新开同角色会话，历史在所选消息处截止，可用「返回原消息」回到原会话。引用和转发保留原始归属。长文件的近期内容可直接续聊，召回索引按批补齐。
5. **管理用途。** 在「历史来源与用途」查看或修改本次整理选择。缺少整理模型、角色授权或配额时，窗口区分相应状态。暂停整理可保留继续聊天的能力。撤回历史使用后，原始气泡仍可本机查看，取材、精确引用及派生记忆停止使用该来源。已呈现的 PCAR 发言保留。
6. **升级或迁移。** 旧原型会话可在来源详情中选回同一原文件，确认本人和范围后继续使用原事件。迁移到新机器或更换接收模型时，重新核对用途。回退旧程序时，先保留新版业务数据，再使用升级前备份。
