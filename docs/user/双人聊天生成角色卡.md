# 从双人聊天记录生成角色卡

打开当前仓库或 v0.3 桌面包中的 `启动PCAR-新版.bat`，在「人物 → 新建角色」使用「从聊天记录生成」。新实例自带经审定的提示词。需要从文件导入时，点「导入提示词文件」，在桌面包根目录选择 **双人角色卡提示词.json**。使用源码工作区时，直接使用相同的内置版本即可。窗口会显示当前使用的版本。提示词文件可以重复使用。

从旧工作台升级时，先退出原窗口，启动新版并选择原来的数据目录。首次使用新版会补齐界面依赖。

1. **选择聊天记录。** 支持 Moect v1.3.0 的微信私聊 Markdown，也支持用二级标题逐条标明说话人的通用 Markdown。预览双方、日期和消息数，有重名或引文归属问题时可逐条修正。
2. **确认并分析。** 核对本次会发给官方 DeepSeek 的脱敏片段和调用范围，按窗口提示配置你自己的模型连接。确认后，PCAR 分别提炼两人的观察，按需归并，再用一次额外请求同时生成两张卡。步骤和用量在本次导入中记录，云端生成可能产生费用。
3. **核对已填字段。** 切换 A、B 核对人设、语言风格、人物资料及场景。名称和人物介绍为必填项。点击保存或开聊时，页面会提示缺项，并将光标定位到第一处。选填项可按需补充，待核对的冲突和空项会从聊天提示词中省略。
4. **预览、保存与开聊。** 在同一文本框中切换预览 A、B 的人设提示词。可分别保存角色。确认开聊时会一并保存符合必填条件的另一方，并进入当前选中的人物。另一方缺项时保留草稿。可选择从空白开始或带历史开聊。桌面端可为当前角色核准场景材料，待模型连接与用途授权就绪时启用。[历史聊天接续](历史聊天接续.md)

提示词包版本为 `pcar-import-prompts-v1`。它包含三段通用模板，发布清单记录了 SHA-256。模板的加载与导入均在本机完成，模型请求在用户确认本次资料范围后发出。 [详细验收记录](../acceptance/LT-13-双人成卡与场景启用.md)
