# PCAR 正式版 1.2.0 Windows 使用指南

## 安装并连接 DeepSeek

1. 在 Windows 11 x64 上双击 `PCAR-1.2.0-Windows-x64-Setup.exe` 安装。
2. 打开「PCAR 社区版」，在「DeepSeek 官方连接」填写并验证自己的官方 API Key。正文使用 DeepSeek V4 Pro，建卡、决策、整理和联网取材使用 DeepSeek V4.1 Flash。
3. 选择已有角色，或通过「人物 → 新建角色」建立一位新角色。

首次打开 1.2.0 时会显示更新说明。之后可在首页「公告」查看历史更新和作者通知，点击「刷新」可检查公开公告。

安装程序随附 Python 3.12、运行依赖、BGE 本地检索模型和 WebView2 离线安装程序。连接 DeepSeek 时优先使用已启用的 Windows 系统代理，无系统代理时直接连接官方 HTTPS 接口。在线聊天、建卡、记忆整理和联网查找会按 DeepSeek 账户的实际用量计费。

## 从聊天记录生成角色卡

- **微信记录**可选择 Moect v1.3.0 导出的双人私聊 Markdown。
- **DeepSeek 对话**可整理为通用 Markdown。每条消息前用二级标题标记说话人，例如 `## 用户` 和 `## 助手`，下一行接该条原文。使用已有导出工具时，核对导出的 `.md` 是否按消息保留说话人。

在「人物 → 新建角色 → 从聊天记录生成」选择文件，确认双方对应的角色和本次分析的内容，再发起分析。工作台会预填可从发言提炼出的人物特质、表达风格、价值观和背景。你可以对照原话修改已填内容，并为留空的可选资料补充已知信息。

填写名称和人物介绍即可保存。确认前可在同一个文本框中预览人设提示词并切换 A、B。空白选填项和未处理的冲突字段会从提示词中省略。确认开聊时，系统进入当前角色的对话，并保存已具备必填信息的另一张卡。另一方缺项时保留草稿。选择「带历史开始」可将旧对话接到所选角色。[历史接续操作](历史聊天接续.md)

## 引用和分支

点击消息旁的「⋯」，或在触屏上长按消息。选择「引用这条消息」即可在输入框中看到引用。回复结合原消息前后和最近对话，最多读取 51 条历史消息。选择「从这里开启分支」会打开同角色的新会话，分支历史在所选消息截止。点击「返回原消息」可回到原会话。

## 记忆和联网查找

在角色设置中开启自动记忆，工作台会在运行时整理聊天，并按新话题找回相关内容。要查公开资料，输入消息后点击「联网查找」，核对选中的片段，首次允许本会话查找后点击「查找并发送」。只把确认的片段交给 DeepSeek 官方搜索。可在「会话授权」撤回许可。使用已登记的本地优先检索流程时，联网范围仍以该会话的授权为准。

## 本机数据

应用默认安装到当前用户的 `%LOCALAPPDATA%\Programs\PCAR Community`。角色、聊天、记忆、模型缓存和加密凭据保存在 `%LOCALAPPDATA%\PCAR Community Data`。卸载会保留数据目录。换机时使用工作台的迁移功能，并在新机重新核对资料用途和接收方。
